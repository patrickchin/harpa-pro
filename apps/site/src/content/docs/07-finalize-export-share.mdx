## Finalize a report

1. Review the generated report and its placed photos.
2. Wait for generation and saving indicators to finish.
3. Tap **Finalize report**.
4. Review the confirmation and finalize the draft.

Finalizing makes the report read-only. It prevents later note changes or
background updates from changing the approved record.

## Preview the PDF

Open the finalized report's actions menu and tap **View PDF**. Harpa Pro builds
the PDF on your iPhone and opens the in-app preview. From the preview, you can
share the file or open it in an external PDF viewer.

## Save or share the PDF

Open **Report Actions** and choose:

- **Save PDF** to generate the file and keep it in the app's documents area.
- **Share PDF** to generate the file and open the iPhone share sheet.
- **View PDF** to inspect the result before sending it.

Harpa Pro regenerates the PDF for each save or share request so the file
reflects the current finalized report.

## Make a correction later

Use **Report Actions** → **Unfinalize report**. After confirmation, the report
returns to draft and can be edited. Finalize it again before distributing the
revised record.

## Good to know

> PDF creation happens on the device. Saving and sharing depend on iPhone file
> and share services, so the available destinations vary by installed apps.

The report title becomes the basis for a safe PDF filename. Source notes are
not appended as a separate PDF section; they remain available in Harpa Pro.

## Troubleshooting

- **Finalize is disabled:** Wait for report generation and autosave to finish.
- **PDF generation fails:** Close the preview, reopen Report Actions, and try
  again after confirming the report loads normally.
- **Open PDF fails:** Use **Share PDF** and choose another viewer.
- **The share sheet is unavailable:** Save the PDF first and open it from a
  device file app.
