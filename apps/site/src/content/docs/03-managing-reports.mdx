## Start a report

1. Open a project and tap **Reports**.
2. Tap **New report**.
3. Harpa Pro creates a draft and opens its note-taking workspace.
4. Add field notes, then generate the first report when you are ready.

Owners and Editors can create reports. A Viewer can open reports but does not
see the new-report control.

## Understand report states

A report has one of two states:

- **Draft:** Notes and report content can change. The workspace includes
  **Notes** and **Report** tabs.
- **Finalized:** The report is read-only and ready to preview, save, or share.
  Source notes remain available from **Report Actions** → **View notes**.

The Reports list groups drafts separately from finalized records so unfinished
work is easy to find.

## Continue or review a report

Tap a draft to reopen its workspace. Tap a finalized report to open the saved
report view. Use the actions button in the report header for PDF actions,
source notes, unfinalizing, or deletion when your role allows those actions.

## Delete a report

Open **Report Actions**, choose **Delete report**, and confirm. Owners can
delete reports; other roles may not see this action. Deletion is permanent.

## Good to know

> Harpa Pro may create the report row before the destination screen finishes
> loading. If a row briefly says **New report**, wait for it to resolve rather
> than tapping **New report** again.

Draft changes and generated content are saved to the project. Pull-to-refresh
is available on project and report lists when another teammate has made a
change.

## Troubleshooting

- **A draft opens without generated content:** Add at least one note, then tap
  **Generate report**.
- **A report row does not open:** Refresh the list and try again after the
  pending row finishes saving.
- **You cannot create a report:** Confirm your project role with the Owner.
- **A finalized report needs changes:** Use **Report Actions** → **Unfinalize
  report**, then edit the returned draft.
