## Generate the first report

1. Add at least one source note to a draft.
2. Tap **Generate report** above the report tabs.
3. Keep the draft open while the button shows **Generating…**.
4. Open **Report** to review the result.

Generation organizes the available notes into report details such as weather,
workers, materials, issues, next steps, and additional sections. Review the
result before finalizing it.

## Let later changes update the draft

After a report exists, adding or removing source notes marks it as needing an
update. While the draft is open, Harpa Pro automatically starts one update at a
time. If more notes change during that update, the next update waits its turn.

The Report tab shows progress. Finalize stays unavailable while generation or
saving is still in progress.

## Request an update yourself

Use the regenerate action when you want to rebuild the report from its current
notes. If the report is known to be behind, the main action reads **Update
report**. When the report is current, the circular-arrow action requests a new
generation.

## Usage limits

AI actions and voice processing may have account limits. If a limit is reached,
the app shows what was used, the effective limit, and when it resets. Open
**Profile** → **Usage This Month** to review current limits and recent activity.

## Good to know

> Generated text is a draft, not a substitute for site review. Check names,
> quantities, dates, issues, and commitments before finalizing.

Automatic updating applies only to drafts. A finalized report stays fixed
until an Owner or Editor unfinalizes it.

## Troubleshooting

- **Generate report is disabled:** Add a source note and wait for pending
  uploads to finish.
- **An update failed:** Read the error on the Report tab and use its retry
  action. The automatic updater pauses while an error is visible.
- **The report still shows old information:** Confirm the source note appears
  under Notes, then request a regeneration.
- **A usage dialog appears:** Review the reset time in the dialog or on Usage
  History before trying the paid action again.
