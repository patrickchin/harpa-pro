## Open a project

The **Projects** screen lists every project you can access. Each row shows your
role, the project address when one is set, and the latest update date.

Tap a project to open its overview. The overview shows the number of reports,
the number of drafts, the most recent report activity, and shortcuts to
**Reports** and **Members**.

## Add or update a project

To add a project:

1. Tap **Add project** on the Projects screen.
2. Enter a project name.
3. Optionally enter an address and client name.
4. Tap **Create project**.

Owners and Editors can update project details. From the project overview, tap
the pencil action, change the fields, and tap **Save changes**.

## Find previous reports

1. Open the project.
2. Tap **Reports**.
3. Browse the **Drafts** and finalized-report sections.
4. Tap a row to continue a draft or read a finalized report.

Report titles use the saved title when one exists and fall back to the report
number and date. Pull down on the list to refresh it.

## Delete a project

Project deletion is restricted to the project Owner. Open **Edit project**, tap
**Delete project**, review the warning, and confirm. This permanently removes
the project and its reports, so export any records you need first.

## Good to know

> Your role appears on each project. Owners manage the project and its members,
> Editors contribute to reports, and Viewers have read-only access.

The project overview uses server-calculated counts. If a newly created report
does not appear immediately, pull down to refresh before creating another one.

## Troubleshooting

- **A project is missing:** Pull down to refresh. Confirm that the Owner invited
  the same email address you use to sign in.
- **You cannot edit project details:** Your role may be Viewer. Ask the Owner to
  make the change or invite you as an Editor.
- **Report counts look old:** Refresh the project overview and then the Reports
  screen.
- **Delete is unavailable:** Only the project Owner can delete the project.
