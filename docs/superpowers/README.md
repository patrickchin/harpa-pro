# Historical implementation artifacts

The dated files in `specs/` and `plans/` preserve implementation decisions and
working plans from May and June 2026. They are not the current architecture or
product backlog.

Use `docs/v4/` and the current implementation for present behavior. Treat an
unchecked task in a historical plan as recorded plan state, not as active work.
Verify commands, routes, paths, and provider behavior before you reuse a step.
