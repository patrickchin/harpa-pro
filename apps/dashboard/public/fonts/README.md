# Dashboard fonts

Manrope (body/controls, 400–700) and Plus Jakarta Sans (headings, 500–700)
are Latin variable WOFF2 subsets downloaded from Google Fonts on 2026-10-16.
Both are distributed under the SIL Open Font License 1.1; the original
licenses are included beside the assets.

Sources: [Manrope](https://github.com/google/fonts/tree/main/ofl/manrope)
and [Plus Jakarta Sans](https://github.com/google/fonts/tree/main/ofl/plusjakartasans).

Files are served locally with font-display swap. Other scripts fall back to
the system sans font. See docs/v4/design-dashboard-workspace-refresh.md.
