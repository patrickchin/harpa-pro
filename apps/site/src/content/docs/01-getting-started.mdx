## Install Harpa Pro

Harpa Pro is available for iPhone from the
[App Store](https://apps.apple.com/us/app/harpa-pro/id6776759817).
Android and web apps are planned, but they are not part of the current public
release.

## Sign in with your email

1. Open Harpa Pro.
2. Enter your email address and tap **Send Code**.
3. Open the Harpa Pro email and copy the six-digit verification code.
4. Return to the app, enter the code, and tap **Verify Code**.
5. If this is your first sign-in, enter your full name and, optionally, your
   company name. Tap **Get started**.

A new email address creates a new Harpa Pro account after the code is verified.
You do not need a separate registration screen or password.

## Create your first project

1. On **Projects**, tap **Add project**.
2. Enter a project name. This is the only required field.
3. Add the project address and client name when they are useful on reports.
4. Tap **Create project**.

The project overview is your starting point for reports, project details, and
members.

## Good to know

> Verification codes are sent to the email address you entered. Harpa Pro
> waits 30 seconds before enabling **Resend Code** again.

Your full name identifies you to teammates. Your company name also appears in
profile and exported-report details. You can update both later from **Profile**
→ **Account Details**.

## Troubleshooting

- **The code has not arrived:** Check junk mail, confirm the address shown in
  the app, then use **Resend Code** when the countdown finishes.
- **The address is wrong:** Tap **Change Email** and request a new code.
- **The code is rejected:** Use the latest code you received and enter all six
  digits. Request another code if necessary.
- **The first screen looks empty:** Pull down to refresh. If the problem
  continues, open **Profile** and use **Clear cached data**.
